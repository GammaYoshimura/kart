# Project-specific instructions for contributors and coding agents

## Android work is deferred

The Android port is explicitly deferred until Phase 11 of `ROADMAP.md`. During earlier phases, do not configure Android export presets, install or troubleshoot Android build templates, inspect or change Android SDK/JDK/keystore settings, create Android builds, run Android checks, or add Android jobs to CI. Treat the Android milestones in Phase 0 (F0-069, F0-070, F0-073, and any Android portion of F0-076) as deferred; they do not block progress on Windows or Linux. Resume Android work only when Phase 11 begins or the user explicitly requests it. Keep this deferral in mind when continuing the roadmap.
