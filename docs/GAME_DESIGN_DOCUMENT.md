# Documento de diseño del juego

## Pilares

1. **Conducción inmediata:** aceleración responsiva, derrapes legibles, saltos y turbo con controles accesibles.
2. **Carreras llenas de decisiones:** elegir trazada, momento de usar objetos y riesgo de atajos cambia el resultado.
3. **Competición amable:** reglas claras, recuperación rápida tras un choque y opciones para jugar en solitario, local y online.
4. **Mundo propio:** personajes, vehículos, pistas, nombres, música e iconografía originales.

## Modos previstos

| Modo | Formato | Objetivo |
|---|---|---|
| Gran Premio | 12 corredores, 4 pistas | Acumular puntos a lo largo de una copa. |
| Carrera rápida | 1–12 corredores | Elegir pista, vueltas, objetos y dificultad. |
| Contrarreloj | 1 corredor + fantasma | Mejorar el tiempo y compartir una repetición verificable. |
| Batalla de globos | 2–12 corredores | Conservar globos y puntuar impactos con objetos. |
| Carrera online | 8–12 corredores | Competir en salas privadas o matchmaking. |

## Objetos iniciales

| Objeto | Uso |
|---|---|
| Cohete Rastreador | Persigue al rival más próximo por delante. |
| Bomba Rebote | Explosión de área tras un temporizador corto. |
| Escudo Magnético | Bloquea un impacto y atrae objetos cercanos. |
| Turbo de Bolsillo | Impulso breve hacia delante. |
| Mancha de Aceite | Hace patinar a quien la pisa. |
| Mina Saltarina | Trampa visible que se activa al contacto. |
| Nube de Tinta | Reduce temporalmente la visibilidad del rival. |
| Pulso Eléctrico | Interrumpe el uso de objetos en un radio corto. |
| Ala Planeadora | Aumenta el control durante un salto. |

## Copa inicial

La primera copa reúne cuatro circuitos originales: Costa Sol Naciente, Cañón Ferroviario, Complejo Turbo-Neón y Ruinas del Valle Esmeralda. Sus trazados serán diseñados a mano.
