# Flujo de trabajo con Godot MCP

Para cada micro-milestone:
1. Editar scripts, recursos o escenas dentro del proyecto.
2. Ejecutar las comprobaciones automatizadas disponibles en modo headless.
3. Abrir o ejecutar la escena pertinente con Godot MCP.
4. Consultar get_debug_output y corregir errores antes de cerrar la tarea.
5. Guardar las escenas con save_scene cuando se hayan editado desde el editor/MCP.
